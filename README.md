# Accessible India

**One app. Different abilities. Equal access.**

Hackathon MVP with three modes:
- Vision Assistance
- Essential Sign Communication
- Accessible Route Finder

## Development
This repository is intentionally structured so the project can be developed and understood in VS Code, then pushed to GitHub and imported into Replit.

## Security
Never commit `.env` or real API keys. Put secrets in local environment variables and, later, Replit Secrets.
