# AI usage disclosure

## Development tools

- **Replit Agent**: project scaffolding, implementation assistance, debugging and documentation.
- **ChatGPT**: architecture planning, code explanation and documentation support.
- **Gemini**: image understanding in Vision Assistance when `GEMINI_API_KEY` is configured.

The developer remains responsible for reviewing generated code, choosing the final architecture, testing important flows, removing unsafe defaults and explaining the implementation.

## External libraries

This project credits React, React DOM, Vite, Express, CORS, dotenv, concurrently, MediaPipe Tasks Vision and the browser Web Speech API. Check each project’s license and documentation before redistribution.
